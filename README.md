# AI LifeOS - Backend

Live API: https://ai-life0s-zahra.bonto.run

## Endpoints
- POST /api/profile — Create user profile
- GET /api/profile/:userId — Get user profile
- POST /api/timeline — AI career timeline scenarios
- POST /api/roadmap — AI learning roadmap
- POST /api/projects — AI project suggestions
- POST /api/resume — AI resume/cover letter generator
- POST /api/readiness — AI job readiness analysis

## Tech Stack
Node.js, Express.js, Firebase Firestore, Firebase Admin SDK, Groq (Llama 3.1) for AI
